# D&D 5R｜2024 創角法術速覽語句校正

本修正只處理**角色創建第七步的效果短預覽**，保留目前已驗證的攻擊／豁免／動作／優劣勢／13 種傷害語意配色。法術規則的 Source of Truth 仍為 `assets/data/spells-phb-2024.js`、`assets/data/spell-rules-2024.js`；`assets/creator-spell-preview-2024.js` 的完整機械預覽、法術詳情、2014 隔離與 JSON/PDF 管線均不改。

## 根因與取捨

前一版 `assets/creator-spell-glance-2024.js` 將已核對的機制投影以 `；` 拆開，最多保留 112 字；首段太長時允許在逗點或第 108 字切斷，並在後面加上 `…`。因此玩家可能看到不完整條件或孤立資料，例如：

- 「遠端法術攻擊,2d12 閃電傷害」缺少自然語句連接。
- 「使一隻野獸對你友善；豁免 感知…」把豁免拆成破碎的第二句。
- 《冷凍射線》預覽重複命中後的同一筆傷害。
- 《加速術》重複寫速度加倍；《魔能爆》預覽混入等級提升效果。
- 文字片段後方有太多 `…`，但並非玩家看得懂的完整句子。

本輪從全部 391 道既有衍生預覽做語法層審查：修正中文標點與常見攻擊／豁免省略句型；短預覽一律保留第一個已整理的機制效果，**不再依固定字元任意切斷**。次要句子只在確實屬於同一個既有簡明摘要、篇幅短且有獨立語意時才採用；自完整法術規則自動擷取的長段說明不再混入預覽。豁免類補充以括號呈現，避免句尾只有「豁免 感知」；必要的基本傷害骰保留。

完整條件、例外與升環效果仍一律可透過法術名稱開啟原本的規則詳情。沒有把速覽當作完整規則敘述。
