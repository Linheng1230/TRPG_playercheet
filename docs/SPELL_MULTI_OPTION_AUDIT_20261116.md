# D&D 5R 2024 零環與一環多選效果重點排版驗收

**範圍：** 8 道具有明確效果選項標題的法術，合計 34 個選項。既有《四象法門》5 項保留，本輪新增 7 道／29 項。資料來源只讀網站 5RTools canonical `SPELLS`；本文件不是法術正文副本。

## 展示規則

- 只改 `assets/cantrip-tooltip-2024.js` 共用 `formatSpellRuleHTML` 顯示層，選項名稱維持金色粗體；第一個核心效果子句再加粗，其餘條件、例子與限制維持一般字重。
- 禁止為了強調而改動原句、標點、骰值、傷害類型、豁免或法術位。所有文字需與 canonical 正文（忽略空白）一致；2014 以及 2024 二環維持舊顯示器。
- 2024《命令術》《造水術／枯水術》在來源中把「選擇其一」導言和第一個選項寫在同一句；顯示時拆成導言段與金色選項標題，原文與順序維持一致。
- 《尋獲魔寵》的「戰鬥」將核心動作描述加粗，保留前面的同盟身分句、後續攻擊限制為一般字重。
- 強調區塊不得有第二層邊框／底色，也不得破壞原先的傷害、豁免、優勢／劣勢或魔法動作色票。

## QA 驗收

- **可重跑專項：** `tests/qa-spell-multi-option-leads-20261116.js`。逐一對照 34 個選項，驗證 98 道原文、tooltip、法術圖鑑樣式、深淺背景對比及 2014／二環隔離。
- **尺寸：** 桌機 1440px、手機 390px、窄螢幕 320px，另需真實玩家入口操作與 GitHub Pages 更新後的新鮮載入。
- **發布門檻：** 原有 38 項 Release Gate、PDF／JSON、其他法術小卡回歸、GitHub Pages 成功部署與 Live UAT；一項未通過不得標記完成。
- **其他工作邊界：** 使用者另提出「創角手機法術列表文字蓋住下張卡片」、「法術詳情下捲後關閉叉叉消失」。這是獨立未完成的手機 UI 問題，不能用本次多選選項的 QA PASS 宣稱已修復；須另行具體驗收與修復。
